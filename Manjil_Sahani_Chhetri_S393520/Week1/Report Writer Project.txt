Report Writer Project Ð 3 Week Work PlanWeek 1: Research and Project SetupActivities:* Researched the purpose and functionality of Report Writer systems.* Analysed the roles and skills required for report development, data analysis, and visualization.* Researched existing reporting tools and technologies.* Installed and configured development tools, including Visual Studio and Visual Studio Code.* Created and configured GitHub repository for project management and version control.* Prepared a learning plan and project roadmap.* Completed basic Excel learning modules through Microsoft Learn.* Started learning Power BI fundamentals and explored basic reporting features.* Documented initial project ideas, requirements, and possible features.Expected Outcomes:* Understanding of project scope and required technologies.* Development environment successfully configured.* Initial project documentation completed.Week 2: Requirements Analysis and DesignActivities:* Gather and analyse functional and non-functional requirements for the Report Writer system.* Identify target users and their reporting needs.* Define key features and system functionalities.* Research database requirements and data sources for report generation.* Create initial system design diagrams and workflow models.* Explore Power BI reporting features and dashboard creation.* Continue improving Excel skills for data preparation and analysis.* Update GitHub repository with design documents and progress updates.Expected Outcomes:* Clear understanding of system requirements.* Initial system design completed.* Better understanding of reporting and visualization techniques.Week 3: Prototype Development and Testing PreparationActivities:* Start developing the initial prototype of the Report Writer system.* Create basic user interface or report templates.* Implement basic data handling and report generation functions.* Connect sample datasets for testing purposes.* Create sample reports and visualizations using Power BI.* Test initial features and identify possible improvements.* Document development progress and update GitHub repository.* Review completed work and prepare plans for future development stages.Expected Outcomes:* Basic prototype developed.* Initial testing completed.* Project progress documented in GitHub.
