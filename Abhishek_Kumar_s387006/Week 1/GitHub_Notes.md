# Git & GitHub Notes

## 1. Git

Git is a version control system used to track changes in source code and files.

### Key Concepts
- **Repository:** A project directory tracked by Git.
- **Commit:** A saved snapshot of changes.
- **Branch:** A separate line of development.
- **Working Directory:** The files you are currently working on.
- **Staging Area:** The area where changes are prepared before committing.

## 2. GitHub

GitHub is a platform for hosting Git repositories and collaborating on projects.

### Common Git/GitHub Operations

```bash
git init
git clone <repository-url>
git status
git add .
git commit -m "message"
git push
git pull
git branch
git checkout <branch-name>
```

## 3. Important Concepts

### Clone
Creates a local copy of a remote GitHub repository.

### Add
Moves changes to the staging area.

### Commit
Records staged changes with a message.

### Push
Uploads local commits to the remote GitHub repository.

### Pull
Downloads and integrates changes from the remote repository.

### Branch
Allows development to happen separately from the main branch.

### Pull Request
A request to merge changes from one branch into another.

### Merge
Combines changes from different branches.

### .gitignore
Specifies files and folders that Git should not track.

## 4. Basic Workflow

1. Clone or create a repository.
2. Create or modify files.
3. Check changes using `git status`.
4. Stage changes using `git add`.
5. Commit changes using `git commit`.
6. Push changes to GitHub using `git push`.
